## 6. 还剩什么（明确不做 / 待排期）

到这里「复审能直接改的」都改了；下面这些是**有意的取舍或需要另一轮**，不是漏掉的 bug：

- **设置保存条**：✅ 收敛为「页面级草稿用粘性保存条 + 未保存标记」（看板外观 / 角色与模型 / 自动派单），保存成功后自动清脏；**其余分区保留分区保存/即时保存**——它们保存的是不同对象（单个仓库、单个机器人、单个环境），合成一个页面级草稿会误保存，属于有意不合并。
- **需求矩阵行内编辑 / 批量覆盖验收条件**：✅ 已做——「编辑」在矩阵表格上方就地展开（自动滚过去），勾选多个功能点可批量替换验收条件（id 按位置复用，删掉的条件上的用例变「未挂条件」）。
- **需求文档改版 → 受影响用例标复跑**：✅ 已做（只标不改）——`requirementDocUpdatedAt` + `caseNeedsRerun`，矩阵 / 抽屉测试页 / 影响面三处都会标「需复跑」；自动重置结果仍没做。
- **版本审批可重复记录**：同一版本可以点多次审批（每次留一条记录），没有做幂等/撤回。
- **GitLab 真令牌端到端**：协议链路已用 mock **端到端**验过（2026-11-24，12 项断言全绿，`tools/verify-gitlab-facts.mjs` 顺带修成「卡必须挂需求」）；**真实令牌/项目仍未接**，需要凭据才能验。
- **老审计的纯视觉项**：项目页首屏空白、权限审计页过长、数据备份页回滚与导出同权重 —— ✅ 本轮已做（见 §7）。
- **数据问题**：`REQ-2026-007` 标了已交付但没有验收签字（存在 .218 台账里，不是代码）。
- **流程**：PR 未合并、版本号/CHANGELOG/tag 未动、本地 GUI 未重启——按规矩等用户确认。
